Address Domain: The address information of a child node, with a default address of 1 .
Function code: Indicates the action to be executed by the server, and the valid code word
range is decimal 1-255 (128-255 isforexception response protection)
When sending messages from the client to the server device, the function code field
notifies the server of which operation to perform (the function code contains a lot of
content, it is recommended to refer to the Modbus protocol manual)
Data: The content of transmitted data. In a certain request, the data can be
non-existent (0 length) in which case the server does not need any additional
information, and the function code only describes the operation.
Error verification: Verify whether the received and sent data is correct.
If there are no errors related to requesting Modbus functionality in a correctly received
Modbus ADU, then the response data domain from the serverto the client includes the
request data.lf there is an error related to requesting Modbus functionality, the domain
includes an exception code that the server application can use to determine the next
operation to perform.
