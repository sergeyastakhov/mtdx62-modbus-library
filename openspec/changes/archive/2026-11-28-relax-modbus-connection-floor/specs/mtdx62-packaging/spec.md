# Spec Delta

## ADDED Requirements

### Requirement: Нижняя граница совпадает со стеком Home Assistant

Библиотека SHALL требовать ту минимальную версию базовой библиотеки, которую ставит заявленная
версия Home Assistant, если код не опирается на исправление в более новой версии.

Если исправление всё-таки нужно, нижняя граница SHALL быть версией с этим исправлением, а README
SHALL объяснять, что именно исправлено.

#### Scenario: Установка на старую версию Home Assistant

- **WHEN** библиотека ставится на Home Assistant 2026.10, где `modbus-connection` 4.12.3
- **THEN** установка не требует версии выше и не подменяет зависимость ядра

#### Scenario: Код опирается на исправление

- **WHEN** библиотека использует поведение, исправленное в версии 4.12.8
- **THEN** нижняя граница — 4.12.8, и в README сказано, какое исправление имеется в виду

### Requirement: Совместимость с границей проверяется

CI SHALL прогонять набор тестов на нижней границе зависимости и на последней версии. Заявление о
совместимости без прогона MUST NOT считаться проверенным.

#### Scenario: Нижняя граница в матрице

- **WHEN** выполняется CI
- **THEN** тесты идут на версии из нижней границы и на последней, и обе сборки обязаны быть зелёными

### Requirement: README объясняет границу

README SHALL называть версию, которую ставит заявленная версия Home Assistant, и SHALL
рекомендовать более новые версии, если они содержат исправления, полезные библиотеке.

#### Scenario: Читатель выбирает версию

- **WHEN** человек читает README, чтобы понять, какую версию зависимости взять
- **THEN** он видит нижнюю границу, причину именно такой границы и рекомендацию обновиться
