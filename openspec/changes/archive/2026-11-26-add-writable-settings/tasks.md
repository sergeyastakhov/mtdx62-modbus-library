## 3. Тесты

- [x] 3.1 `writable_fields()`: состав из тринадцати параметров, порядок, границы, единицы,

- [x] 3.4 Подтверждение: успешная запись обновляет кеш; зажатое устройством значение даёт

- [x] 3.5 Ошибки обмена: отказ устройства и таймаут проходят как есть, кеш не меняется
