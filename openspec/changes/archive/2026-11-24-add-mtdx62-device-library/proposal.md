# Proposal

## Why

Датчик отдаёт наружу десять регистров, которые нужно читать правильно: у каждого свой
масштаб, часть значений склеена из двух регистров, а код состояния — числовой код с шестью
известными значениями. Если разбирать это прямо в интеграции Home Assistant, то проверить
разбор можно будет только через Home Assistant и только с железом.

Библиотека `mtdx62` переносит карту регистров в отдельный пакет: его можно тестировать на
mock-бэкенде без датчика и без Home Assistant, а интеграция получает типизированный объект
устройства и не знает числовых адресов.

## What Changes

- Появляется пакет `mtdx62` на PyPI, построенный на `modbus-connection`.
- Верхний объект `Mtdx62Device` принимает `ModbusUnit` и отдаёт две подсистемы:
  - `readings` — измерения из входных регистров: присутствие, освещённость, расстояние,
    код состояния, версии приложения и радара;
  - `settings` — параметры устройства из holding-регистров, только для чтения.
- Разбор значений: расстояние в метрах с шагом 0.01, освещённость в люксах, версии собираются
  из двух регистров в строку `1.2.3`, код состояния переводится в перечисление с отдельным
  исходом «код неизвестен».
- Чтение измерений укладывается в один блочный запрос; параметры читаются отдельным запросом
  только по требованию.
- Библиотека ничего не пишет в устройство: запись параметров появится отдельным изменением.
- Библиотека не зависит от Home Assistant и не открывает соединений: соединение даёт
  `modbus-connection`, юнит передаёт вызывающая сторона.

## Capabilities

### New Capabilities

- `mtdx62-registers`: карта регистров датчика и её разбор — что библиотека читает, как
  декодирует значения и как ведёт себя, когда устройство молчит или отдаёт неизвестный код.

### Modified Capabilities

Нет: это первая библиотека проекта, `openspec/specs/` пока пуст.

## Impact

- Новый репозиторий `libraries/mtdx62` (PyPI, MIT), версия `0.1.0`.
- Зависимости: `modbus-connection[tmodbus]`. Прямой зависимости от `pymodbus`, `pyserial`
  или Home Assistant нет.
- Потребитель — интеграция `integrations/mtdx62`; при изменении контракта ломается её код,
  поэтому ломающие правки требуют мажорной версии.
- Тесты идут на mock-бэкенде `modbus-connection`, без железа и без Home Assistant.
